# Student Management System – OOP

A Python-based Student Management System CLI built using Object-Oriented Programming. It allows users to add, display, search, and delete student records with JSON data storage, input validation, exception handling, and a modular structure.

## Features

- Add students
- Display students
- Search students by name or roll number
- Delete students
- JSON data storage
- Input validation
- Exception handling

## Technologies

Python • JSON • OOP • File Handling • Exception Handling

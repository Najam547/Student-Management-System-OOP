# Student Management System – OOP

A Python-based Student Management System CLI developed using Object-Oriented Programming. It allows users to add, display, search, and delete student records while using JSON for data storage, input validation, exception handling, and a modular structure.

## Features

- Add students
- Display students
- Search students by name or roll number
- Delete students
- JSON data storage
- Input validation
- Exception handling
- Object-Oriented Programming

## Technologies

Python • JSON • OOP • File Handling • Exception Handling 

## How It Works

1. Add a student
2. Display all students
3. Search for a student
4. Delete a student
5. Store student data in a JSON file
